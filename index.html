01 — MSc FINAL PROJECT

Understanding ransomware.
One feature at a time.

A Python-based classifier that analyses static Windows executable features with pefile, without running the file. Built with pandas and scikit-learn using a 100-tree random forest.

62,485labelled samples
99.57%held-out test accuracy

Dataset evaluation using a 30% held-out test set. This result does not establish detection performance on unseen real-world threats.
