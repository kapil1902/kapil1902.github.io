# Kapilsurya Rajendran — Portfolio

A responsive, animated portfolio built with plain HTML, CSS and JavaScript. No build tools, paid services or API keys required.

## View
Open index.html in your browser. Keep style.css, script.js and Resume_kapil.pdf beside it.

## Publish on GitHub Pages
1. Upload all four files to the root of your portfolio repository (not inside an extra folder).
2. In repository Settings → Pages, choose Deploy from a branch, select main and / (root), then Save.
3. GitHub will display your website address after deployment.

## Design
Warm ivory, violet and terracotta; orbiting security illustration; scrolling typography; animated project graphics; scroll reveals; hover effects. Mobile layouts and keyboard navigation included. The Pause motion control pauses decorative animations; the page respects the operating system’s reduced motion preference. Content remains visible if JavaScript is disabled.

## Content
Content and URLs are taken from the supplied Kapil résumé. Ransomware accuracy is labelled as a dataset test result. No invented internship duties, certifications, rankings or testimonials are included.

To edit content, change index.html. Colours and responsive layouts live in style.css; interactions live in script.js. Replace Resume_kapil.pdf to update the downloadable résumé.
